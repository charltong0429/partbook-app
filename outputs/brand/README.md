# Partbook Brand Package

本目录是 Social Content OS 项目的可复用品牌包。当前推荐工作名为 **Partbook**，仍需经过 24 小时口头测试、目标用户首听测试与正式商标清查后锁定。

## 文件

- `brand.yaml`：品牌包清单与状态
- `context.md`：品牌上下文与 Naming Brief
- `naming.md`：命名过程、候选评分、域名与 prior-art 检查
- `positioning.md`：品牌定位
- `identity.md`：Logo 与视觉识别方向
- `messaging.md`：Tagline、价值主张与消息层级
- `guidelines.md`：品牌使用规范
- `assets/`：未来存放正式 Logo、图标与模板

## 当前建议

- **推荐名**：Partbook
- **推荐 Tagline**：One source. Many trusted voices.
- **推荐域名**：`usepartbook.com`
- **推荐 GitHub 组织**：`partbookhq`
- **状态**：推荐工作名，未注册、未购买、未完成法律清查
