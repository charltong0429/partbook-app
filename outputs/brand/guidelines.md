# TaurisWeft Brand Essentials

## 1. Foundation

**Mission**：让专业人士和企业团队持续把真实知识变成有个人辨识度、跨平台适配且值得署名发布的内容。

**Vision**：成为专业声音的 AI 编辑基础设施，让企业叙事不再依赖同质化转发。

**Values**：

- **Human agency**：发布与高风险互动由人决定。
- **Source-grounded truth**：事实性主张必须能被核验。
- **Individual voice**：公司一致性不等于员工同声同句。
- **Useful specificity**：输出必须具体到能被编辑、使用和衡量。
- **Responsible automation**：自动化有边界、有记录、可撤销。

**Personality**：清醒、可信、编辑感、克制、有判断。

**Positioning**：TaurisWeft 是面向 B2B 专业人士与团队的 AI 编辑系统，把可信研究变成每个人、每个平台都适合发布的独特内容。

## 2. Logo

- 主 Logo 为编织式 `T/W` symbol + TaurisWeft wordmark；竖向经线形成 `T` 的稳定骨架，三条横向纬线以留白形成 `W` 的节奏。
- 允许横向、竖向、icon-only、单色反白四种版本。
- 安全空间至少等于 symbol 内部书脊宽度的 2 倍。
- 最小尺寸：完整 lockup 96px 宽；icon 16px。
- 不拉伸、不描边、不加阴影、不使用未批准渐变、不放在繁杂照片上、不替换 wordmark 字体。

正式 Logo 文件尚未绘制；本条为制作规范，不代表已有最终商标图形。

## 4. Typography

- Brand / Display：Instrument Sans 600–700。
- Editorial：Newsreader 400–600，仅用于观点与研究内容。
- UI：Geist Sans 400–600；中文 fallback 使用 PingFang SC / Noto Sans SC。
- 标题用 sentence case；按钮用动词开头；不使用全大写长句。

## 5. Voice

**Voice essence**：像一位有证据、有编辑判断、尊重作者本人声音的高级编辑。

| Do | Don't |
|---|---|
| 先给结论，再给依据 | 堆砌背景后才说重点 |
| 标明事实、推断与建议 | 把模型推断写成事实 |
| 使用具体动词和数字 | 使用空泛形容词 |
| 承认不确定性 | 假装无所不知 |
| 让作者保留最后决定 | 用自动化替代责任 |

**We say**：source、evidence、angle、voice、draft、review、ready、publish、profile、campaign、人工确认、可核验、个人判断。

**We don't say**：magic、viral、effortless、fully automatic、revolutionary、AI-powered everything、替你发帖、控制员工账号。

## 6. Messaging

- **Core message**：把可信研究变成每位专业人士、每个平台都适合发布的内容。
- **Tagline**：One source. Many trusted voices.
- **Hero support**：Research, shape and review every professional voice from one shared source.

## 7. Product UI

- 主流程固定为 `Source → Brief → Angle → Draft → Review → Ready`。
- AI 生成中显示当前步骤、已使用 source 数和预计等待时间。
- 事实性句子允许查看 source；无 source 的观点明确标记为 opinion。
- `Publish` 与 `Approve external action` 使用高摩擦确认，不与普通 Save 按钮并列。
- 空状态提供一个可运行 example，而不是只显示插画。
- 错误状态保留用户输入与草稿，允许 retry、change model 或 fallback to template。

## 8. Social & Content Templates

- LinkedIn：单一主观点、清晰段落、来源可选放评论或末尾；避免 emoji 堆叠。
- WeChat Moments：中文自然表达、短段落、减少企业术语；不做英文直译。
- Facebook：面向更广泛受众，增加故事和解释，减少行业缩写。
- Company Page：只发布已批准的正式叙事；员工版本必须保留各自专业角度。

## 9. Critical Don'ts

- [ ] 不把 AI 生成内容标成已核验，除非 source coverage 通过。
- [ ] 不在未经授权时抓取或自动控制个人社交账号。
- [ ] 不让团队成员发布完全相同的员工文案。
- [ ] 不用 LinkedIn 蓝或通用 sparkle 作为品牌捷径。
- [ ] 不用点击量或生成量替代 Ready-to-Publish 与复用指标。
- [ ] 不在正式商标清查前投入大规模品牌资产制作。
