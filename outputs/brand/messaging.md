# TaurisWeft Messaging Framework

## 01 — Core Message

TaurisWeft 帮助 B2B 专业人士和企业团队，把可信研究转化为符合个人身份、公司叙事和不同平台语境的可发布内容。

## 02 — Value Proposition

TaurisWeft 把 research、source、draft、visual、preview 与 profile memory 放进一个可审核的编辑工作流。用户不再从空白页开始，也不需要让所有员工复制同一段公司文案；同一事实基础可以长成多个可信、互补、有个人辨识度的专业声部。

## 03 — Tagline Options

1. **One source. Many trusted voices.** — 推荐；最准确覆盖研究、团队矩阵与信任。
2. **Turn expertise into presence.** — 更适合个人品牌与官网 Campaign。
3. **Research. Shape. Publish.** — 功能型，适合产品 onboarding。
4. **Every voice, on message.** — 团队导向，但略带企业传播语气。
5. **Your expertise, ready to publish.** — 个体导向，清晰但差异性较弱。

## 04 — Messaging Hierarchy

### Level 1 — Brand Headline

One source. Many trusted voices.

### Level 2 — Supporting Statement

把可信研究变成每位专业人士、每个平台都适合发布的内容，同时保留个人判断与公司主叙事。

### Level 3 — Key Messages

**Start from evidence, not a blank page**  
TaurisWeft 先组织 source、事实与可用角度，再生成内容。每个事实性主张都能回到依据。
Proof：Research Brief、source card、claim-to-source link。

**Keep the person in the post**  
Personal Brand Memory 记录角色、经历、观点、语气与禁区；生成结果以本人是否愿意署名为质量标准。  
Proof：Voice & Style、版本对比、修改反馈。

**One narrative, different professional angles**  
同一 campaign 不再要求全员转发同一文案；产品、销售、技术、市场各自拥有独立声部。  
Proof：Content Matrix、angle assignment、duplicate warning。

**Ready to publish, never blindly published**  
平台适配、预览、复制、下载与官方 API 接入都经过 Human Approval。  
Proof：Review state、approval log、Copy/Open channel handoff。

### Level 4 — Proof Bank

- 一份 Master Content 可生成不同语言、长度和平台结构的版本。
- LinkedIn 与微信朋友圈使用不同 Platform Profile，不做直译。
- 来源、事实、观点与品牌声明分层存储。
- 用户可编辑、锁定、拒绝与恢复版本。
- 发布前提供完整平台预览。
- 无官方 API 时仍能通过复制文字、下载图片和打开目标应用完成交接。
- 团队可以共享 source 与 company narrative，但个人 voice memory 隔离。
- 高风险外部动作保留人工确认与审计记录。

## 05 — Audience Messaging

### Individual professionals

- **Lead**：把真实专业经验持续变成可见影响力。
- **Proof**：Profile Optimizer、Personal Brand Memory、个人内容支柱、跨语言版本。
- **Avoid**：把产品说成“自动帮你运营账号”。

### B2B team leaders

- **Lead**：让团队围绕一个主题形成互补观点，而不是机械转发。
- **Proof**：Content Matrix、shared campaign、review flow、role-based angles。
- **Avoid**：承诺无人监督的自动互动或增长数字。

### Marketing / Communications

- **Lead**：从统一素材到多声部市场存在，同时保留治理与审批。
- **Proof**：Company Brand、source governance、approval log、channel adapter。
- **Avoid**：把个人账号当作可被公司完全控制的分发节点。

## 06 — Channel Adaptation

| Channel | Headline approach | Tone | Length |
|---|---|---|---|
| Website hero | 结果 + 类别解释 | 克制、自信 | 很短 |
| LinkedIn bio | 专业身份 + 工作流价值 | 专业、具体 | 很短 |
| Sales deck | 问题 → Content Matrix → proof | 判断明确 | 中等 |
| Product onboarding | 三步动词 | 指导性 | 短 |
| WeChat launch post | 创始场景与真实痛点 | 自然、个人 | 中等 |

## 07 — Things Not To Say

- “AI-powered all-in-one social media solution”
- “10x your content”
- “Never write a post again”
- “Fully automate your LinkedIn”
- “Go viral with one click”
- “Revolutionary / game-changing / magical”
