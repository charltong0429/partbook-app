# Naming Report

日期：2026-08-20  
范围：英文/全球中性 SaaS 品牌名、商业域名、GitHub 组织名、初步 prior-art 过滤。

## 1. Naming Brief

- **核心功能**：把可信研究与企业知识转化为符合不同个人身份、公司叙事和平台语境的可发布内容。
- **首要用户**：需要持续经营专业影响力的 B2B 专业人士；随后扩展到产品、销售、市场、技术与国家经理组成的小团队。
- **性格**：权威但不沉重，编辑感强，克制、可信、有判断。
- **品牌层级**：独立 SaaS 品牌，目标是能与 Notion、Linear、Vercel 同桌出现，而不是内部工具名。
- **语言要求**：英文或全球中性；中文用户易读、易说、易拼；不故意错拼。
- **禁区**：不使用 AI、Social、Content、Post、Pilot、Magic、Smart、Neuro 作为命名核心；避免 `-ly / -ify / -ora / Flow / Hub / Forge`。
- **平台要求**：商业域名与 GitHub 组织名为必需；LinkedIn Company 名称需注册前人工确认。精确 `.com` 不是硬门槛。

## 2. Metaphor Territories

内部生成并筛选了 48 个候选，来自三个主隐喻区：

1. **Polyphonic score / Partbook**：同一首作品由多个独立声部组成；各自不同，但共享节奏、主题与结构。
2. **Thread / Weaving**：同一知识经线被不同人的观点纬线织成一张完整叙事网络。
3. **Editorial fold / Angle**：一份可信 source 被折叠、编排成适合不同受众与平台的版本。

按反模式、Phone Test、语义冲突与 prior-art 过滤后，保留以下四个入围名。

## 3. Finalists

### 1) Partbook — 推荐

**15 秒故事**：在早期复调音乐中，Partbook 不是整部总谱，而是某一个声部专属的乐谱。Partbook 把公司的共同主题变成每位员工自己的“声部”：同一事实基础，不同专业视角，最终形成协调但不重复的内容矩阵。

**为什么成立**：

- 同时解释 Personal Brand 与 Company Matrix，不只是“写文案”。
- 可画：打开的书、分开的谱线、多个声部汇成同一节拍。
- 两个常用词，听后可拼；不带 AI 时代标签，生命周期长。
- 模块命名自然：Partbook Research、Studio、Profile、Campaigns。

**风险**：

- 第一次看到时，部分用户可能理解为“零部件目录”；需要 Tagline 在首屏完成类别解释。
- `partbook.com` 已被域名交易平台标价 US$4,695，不建议 MVP 阶段购买。
- 精确 GitHub 组织 `partbook` 已占用。

**可用性快照（2026-08-20）**：

- `usepartbook.com`：检查时可注册，Vercel 报价 US$11.25/年。
- `getpartbook.com`：检查时可注册，Vercel 报价 US$11.25/年。
- GitHub 组织 `partbookhq`、`getpartbook`、`usepartbook`：检查时可用。
- GitHub 名称搜索共 5 个仓库，最高结果 1 star，未发现高影响力同类软件项目。
- LinkedIn Company 名称：未确认。
- Trademark：仅做自动化初筛，未形成法律意见。

**Tagline**：One source. Many trusted voices.

**评分**：94 / 110

### 2) Anglefold

**15 秒故事**：像折纸从同一张纸折出不同面，Anglefold 把同一份 source 折成产品、销售、技术、市场等不同内容角度，再适配到不同平台。

**优势**：独特、可视化强、精确 `.com` 与 `.app` 在检查时均可用；GitHub 名称搜索为 0，组织名可用。

**风险**：不是自然词，首听时情感温度较低；“angle” 容易被理解为营销话术，而非真实专业观点。

**可用性快照**：`anglefold.com`、`anglefold.app`、`anglefold.co`、GitHub `anglefold` 检查时可用。

**Tagline**：Turn one source into every angle.

**评分**：88 / 110

### 3) Threadmark

**15 秒故事**：品牌需要一条长期连贯的 thread，每位专业人士又要留下自己的 mark。产品把连续叙事与个人辨识度放在同一个名字里。

**优势**：两音节、Phone Test 好、Logo 可由线与印记构成；很适合 Brand Memory 与职业身份。

**风险**：`threadmark.com` 属于一家成熟的私募市场资本服务公司；GitHub 还有一个面向 Claude Code/Codex 的同名 AI agent continuity 项目。虽非直接竞品，但会长期增加搜索与商标成本，因此不作为首选。

**可用性快照**：`getthreadmark.com`、`usethreadmark.com`、GitHub `threadmarkhq` 与 `getthreadmark` 检查时可用；精确 `.com/.app/.co` 不可用。

**Tagline**：Build a voice that carries.

**评分**：85 / 110

### 4) Proofweave

**15 秒故事**：事实与来源是经线，个人观点与表达是纬线；只有两者一起织，内容才既可信又有人味。

**优势**：直接拥有“source-grounded + authentic voice”的产品承诺，适合企业信任场景。

**风险**：名字略偏功能型；GitHub 已有小型 AI-assisted mathematics 项目使用 ProofWeave，虽不同类别，但在 AI namespace 内造成轻度噪声。

**可用性快照**：`proofweave.app`、`proofweave.co`、`useproofweave.com` 与 GitHub `proofweavehq` 检查时可用；精确 GitHub 组织已占用。

**Tagline**：Source every claim. Keep every voice.

**评分**：84 / 110

## 4. Killed Candidates

- **Sourcefold**：淘汰。`sourcefold.com` 已重定向至 Cognitude Labs，一家面向 knowledge-intensive professionals 的 applied AI 公司，受众和 AI namespace 过近。
- **Weft / Galley / Rostra / Counterpoint / Braid / Pressmark**：精确域名、组织名或同类 prior-art 密度过高；不降低闸门继续推进。

## 5. Recommendation

选择 **Partbook** 作为 PRD 和后续设计的推荐工作名，但在投入正式 Logo、域名购买或公开发布前完成：

1. 连续 24 小时在产品介绍、会议、口头推荐和域名中反复使用。
2. 让 5 名不参与本次命名的人先听名字，再复述、拼写并猜测产品性格。
3. 对 EUIPO、USPTO、WIPO 与目标国家做正式商标清查，重点覆盖 SaaS、software、marketing、publishing、social media 类别。
4. 人工确认 LinkedIn Company 名称与主要社交 handle。
5. 确认后再注册域名；本次没有购买任何域名。
